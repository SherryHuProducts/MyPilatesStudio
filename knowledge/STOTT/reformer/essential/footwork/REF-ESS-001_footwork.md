# 1. Overview（动作概述）

Footwork 是 STOTT Pilates Reformer Essential 的第一个动作（Exercise 1）。

本动作包含五个不同的脚位（Foot Placement Variants）。

所有变式共享相同的器械设置、固定姿势及整体训练原则。

各变式之间主要区别为脚部放置方式。

# 5. Global Key Points（通用要点）

以下要点适用于整个 Footwork 系列。

- 骨盆和腰椎稳定保持中立位，避免后倾或前倾。
- 稳定整个肋骨架和肩胛骨部位，避免上身紧张。
- 双腿充分伸展（做小幅度变化动作时除外），双膝不要“卡紧”或过度伸展。
- 髋部中心、膝部及踝关节成一条直线。
- 利用股骨肌适度牵拉髌骨（通常需要调动股内侧肌群）。
- 在“脚部练习”和“第二种姿势”中，双腿要均衡锻炼。
- 骨盆保持水平，避免旋转和侧倾。
- 肩膀上部和颈部应避免紧张。

# 7. Principles（训练原理）

教材原理适用于整个 Footwork 系列。

训练目标包括：

- 以腹横肌挤压腹部。
- 稳定腰骨盆部位。
- 以深层盆底肌辅助腹横肌运动。
- 利用腹斜肌防止脊柱伸展。
- 利用腹斜肌和多裂肌阻止身体旋转。
- 利用股内侧肌及股外侧肌适度牵拉髌骨。

教材随后分别说明不同练习阶段的主要肌肉募集方式（共五项）。

详见教材第27页。

# 8. Movement Adjustments（动作调整）

教材提供以下整体动作调整建议：

1. 交替式呼吸。
2. 有节奏的小幅运动。
3. 关节活动末段的有节奏运动。
4. 双脚微分。
5. 使用间隔物。

各调整方法详见教材第27页。
